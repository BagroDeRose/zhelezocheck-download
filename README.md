# ЖелезоЧек — скачать программу

**ЖелезоЧек** — бесплатная портативная программа для Windows. С флешки проверяет б/у компьютер
или ноутбук перед покупкой: видеокарту (в том числе подделку и следы майнинга), процессор,
оперативную память, диски, батарею, журнал ошибок Windows — и выдаёт вердикт
«Брать / Торговаться / Уходить» с понятными причинами. Ничего не устанавливает на проверяемый
компьютер и не пишет на его диски, интернет не нужен.

## Как запустить

1. Распакуйте архив **целиком** на флешку (правой кнопкой → «Извлечь всё»). Внутри — папка
   с `ЖелезоЧек.exe`, `ПРОЧТИ.txt`, `ЛИЦЕНЗИЯ.txt` и служебной папкой `_internal` — её не удаляйте.
2. На проверяемом компьютере запустите `ЖелезоЧек.exe`.
3. Если Windows показывает «Система Windows защитила ваш компьютер» (SmartScreen) — нажмите
   «Подробнее» → «Выполнить в любом случае». Программа не подписана платным сертификатом,
   поэтому Windows её «не знает».

## Системные требования

- Windows 10 или 11, 64-бит;
- около 200 МБ на флешке;
- интернет не нужен.
