# ЖелезоЧек — скачать программу

**ЖелезоЧек** — портативная программа для Windows: с флешки проверяет б/у компьютер или ноутбук
перед покупкой (процессор, память, видеокарта, диски, батарея, журнал ошибок Windows) и выдаёт
вердикт «Брать / Торговаться / Уходить» с понятными причинами.

Последняя версия: **1.1.0** — [страница релиза](https://github.com/BagroDeRose/zhelezocheck-download/releases/latest), файл `ЖелезоЧек-v1.1.0.zip`.

Проверить в PowerShell: `Get-FileHash .\ЖелезоЧек-v1.1.0.zip` — значение должно совпасть.

## Как запустить

1. Распакуйте архив на флешку (папку «ЖелезоЧек» целиком).
2. На проверяемом компьютере запустите `ЖелезоЧек.exe`. Подробнее — в файле `ПРОЧТИ.txt` в архиве.

## Системные требования

- Windows 10 или 11, 64-бит;
- около 500 МБ на флешке;
- интернет не нужен (только для встроенного браузера объявлений).

В этом репозитории нет исходного кода — только архивы программы.
