# Политика конфиденциальности бота и программы «ЖелезоЧек»

Версия 2.0 от 13.10.2026.

Оператор данных — BagroDeRose, контакты: bagroderose@gmail.com, Telegram @BagroDeRose.

Покупатель видит краткую версию этого текста в боте @zhelezocheck_bot: «Помощь» → «🔒 Как мы храним данные».

## 1. Программа «ЖелезоЧек»

Программа **не собирает и не передаёт** данные: сведения о компьютере, отчёты и история проверок
хранятся только в папке программы на флешке пользователя.

## 2. Какие данные хранит бот и зачем

| Данные | Зачем |
|---|---|
| Telegram ID, @username, дата первого и последнего обращения | Отвечать покупателю, показывать его ключи, находить покупки по обращению в поддержку |
| Заказы: тариф, цена, код флешки, статус, номер платежа ЮKassa, версия принятых документов | Выдать ключ после оплаты, разобраться с оплатой, вернуть деньги |
| Выданные ключи: тариф, срок, код флешки, отметка об отзыве | Повторно показать ключ («Мои ключи»), перепривязать, отозвать при возврате |
| Номер телефона — **только если покупатель сам нажал «Поделиться номером»** | Найти покупки, если покупатель сменил аккаунт Telegram |
| Журнал событий: продажи, возвраты, действия владельца | Учёт продаж и разбор спорных случаев |

**Код флешки** — это хеш (необратимое преобразование) её серийного номера: сам серийный номер
и другие сведения о компьютере боту не передаются.

## 3. Чего бот не хранит

- Данные банковской карты: оплата проходит на стороне ЮKassa, бот получает только статус платежа.
- Переписку: бот не сохраняет тексты сообщений, кроме кода флешки в заказе.
- Telegram ID в самом ключе: в ключ попадает псевдоним — по нему нельзя узнать покупателя.

## 4. Сколько хранятся данные

- Данные о покупках (заказы, ключи) — пока действует ключ, и не дольше 3 лет после последней
  покупки: они нужны, чтобы восстановить или перепривязать ключ и разобраться в спорной ситуации.
- Номер телефона — пока покупатель не попросит его удалить.
- Данные пользователей без покупок — пока покупатель не попросит их удалить.

## 5. Кому передаются данные

- **ЮKassa** (ООО НКО «ЮМани») — только то, что нужно для оплаты: сумма, описание товара,
  номер заказа и псевдоним покупателя.
- Больше никому. Данные видит только владелец бота: в панели «Администрирование» и в файле базы
  на своём компьютере.

## 6. Как удалить данные

Напишите владельцу: кнопка «Связаться с нами» в боте, bagroderose@gmail.com или Telegram @BagroDeRose.
Владелец удалит номер телефона и данные профиля. Сведения о покупках, нужные для учёта доходов и
восстановления ключа, хранятся в пределах срока из раздела 4. Выданные ключи после удаления
данных продолжают работать — программа проверяет их без интернета.
